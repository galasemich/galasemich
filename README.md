Desde que soy chica me fascina por un lado la literatura y por el otro lado las ciencias exactas. Siempre combiné lectura voraz de novelas, cuentos y ensayos con una curiosidad filosófica por los sistemas matemáticos y la lógica. Los números y su belleza estructural me fascinan y me desconciertan por igual, pero nunca había podido desarrollar profesionalmente ese interés hasta que encontré la programación y entendí que la creatividad, el hacer *algo* con el código, y la lógica de un sistema formal podían efectivamente confluir. 

## Quién soy
Me formé académicamente en Letras, con orientación en Lingüística. Estos estudios, además de mi interés en la filosofía, la matemática y la lógica, me dieron un bagaje sólido para entender cómo funciona un sistema, cómo es posible formalizar un problema real y, en última instancia, cómo abstraerlo para que se convierta en algo "programable".

Empecé mi recorrido aprendiendo Python, quizás el lenguaje de programación más amigable para empezar. Luego seguí con SQL, aprendí HTML y CSS y finalmente JavaScript, para desarrollar backend con Node.js. 

## Qué hice
Encore es quizás el proyecto que más me enorgullece: es un pequeño framework minimalista que utiliza el módulo http como base para levantar servidores. Mi idea con Encore era *dilucidar qué hay detrás* de un framework como Express, por ejemplo. Desarrollar Encore fue una experiencia interesantístima porque así pude entender cabalmente todos los procesos que un framework abstrae por nosotros. 

Mi primer proyecto web completo es Scriptorium, una aplicación para registrar y trackear lecturas. 

Luego seguí con un proyecto colaborativo, Presupuestar, en el que trabajé con otros equipos (Frontend, Data, UX/UI, QA); desarrollamos una aplicación dirigida a emprendedores para generar presupuestos. 

## Cómo me gusta trabajar
Me importa particularmente el código limpio y eficiente: así como una buena poesía gana en su brevedad y síntesis, una buena porción de código ganará cuando cada línea tenga un propósito claro y vaya en pos de un objetivo. Así me gusta encarar el desarrollo: desmenuzando el problema, diseñando pasos a seguir y tratando de escribir código prolijo, limpio y fácil de mantener. Siempre es posible mejorar, y eso es una de las cosas más lindas de programar. 

## Actualmente...
Quiero seguir formándome en desarrollo web y por ese motivo empecé a aprender React, para tener el trayecto de full-stack completo. Más a título personal y por curiosidad intelectual, me gustaría también aprender C y algo de desarrollo de videojuegos. 

En estos momentos, estoy buscando mi **primera experiencia profesional real** como desarrolladora backend.
